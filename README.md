# �S Bổ Củi Siêu Tốc (Timberjack Web Game)

Trò chơi web arcade **Bổ CỦi Siêu Tốc** lấy cảm hứng từ game kinh điển Timberman, được xây dựng hoàn toàn bằng HTML5 Canvas và Web Audio API.

## 🌔 Tính Năng Nổi Bật

- chặt gỗ liên hoàn hai bên thân cây, né tránh cành cây và chạy Đua với thanh thời gian.
- *Heth thóng 4 Nhân Vật (Skins)*:
- 🲞 *Tiều Phu Cổ Điển*
- 🲗 *Ninja Siêu Tốc*
- 😰 *Hiệp Sĩ Rừng Xanh*
- 🤥 *Rô-bột Laser*
- Hiệu ứng đồ họa mượt mà: Khúc củi văng xoay tròn, nóy đầmo, vệt chém, rung màn hình (Screen Shake).
- Âm thanh tổng hợp sống động qua Web Audio API.
- Lưu kỷ lục & danh hiệu trên LocalStorage.
- Hỗ trợ cả máy tính và điện thoại cảm ứng.
